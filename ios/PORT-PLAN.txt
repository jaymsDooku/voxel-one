Architecture decision
Reuse UIKit, SceneKit and the Java mobile gateway. Keep authoritative online
rules in Java; Swift supplies native input, rendering and offline rules. No JVM,
LWJGL, webview or streaming dependency runs on iOS. Keep City planning unchanged.
Use existing schema 1 until a versioned detail-preserving contract is added;
never silently label schema 1 compatible with desktop fine geometry.

Camera increment (new native qualification pending)
Sandbox camera choice is local, persisted in UserDefaults: first, third, isometric.
The SceneKit renderer reuses its orthographic path for Sandbox without enabling
City planning commands. City still selects its original Plan/Walk behavior.
Third-person lens sweep: <=12 blocks, steps <=0.1 blocks, 0.15-block corner samples;
solid terrain and snapshot boundaries retract the lens. The simple local capsule
hides when the lens is within one block of the eye. This is not a desktop skin port.
Isometric pan stays within loaded X/Z bounds; zoom remains 12..80. Movement recenters
on the player, while panning never moves their authoritative pose. Tap aiming uses
the displayed camera ray, then checks five-block player-eye reach and occlusion.
First-person picking reuses the same bounded DDA traversal with the old semantics.
Pan, zoom, movement and orientation changes clear a prior tap aim. Held movement
also clears on orientation changes. New native tests cover mode persistence,
overview reach rejection, zoom, movement, landscape and walking/jump recovery.

NativeOfflineLoader executes one value-returning operation on a utility queue.
Controller owns at most one pending intent and waits for both save/loader idle;
no synchronous main-queue wait or unbounded load queue. Main callbacks are fenced
by loader generation and controller session UUID. Cancel restores the menu and
invalidates the result; a new request waits for the old operation to leave the worker.
Cold start shows the real menu/loading panel before building the actual world.
File reads stop at 16,000,001 bytes and reject more than 16,000,000; atomic writes
have the same cap. Migration is a validated value transform and does not rewrite
its source. Malformed and oversized saves remain untouched by load failure.
World construction, collision cache building and meshing still run on main; chunk
generation/streaming and incremental mesh work remain open. No device timing claim.
