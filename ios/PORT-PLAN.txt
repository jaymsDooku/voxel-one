Architecture decision
Reuse UIKit, SceneKit and the Java mobile gateway. Keep authoritative online
rules in Java; Swift supplies native input, rendering and offline rules. No JVM,
LWJGL, webview or streaming dependency runs on iOS. Keep City planning unchanged.
Use existing schema 1 until a versioned detail-preserving contract is added;
never silently label schema 1 compatible with desktop fine geometry.

This slice
Jump begins on touch-down and repeats while held. Release, drag exit, touch
cancel, pause, planning, menu, graphics and suspend clear the shared input set.
A full inventory now rejects breaking before changing terrain or inventory.
Tests cover full-bag rejection, partial-stack collection and empty-slot collection.
The native workflow suite adds held-jump release, pause and background regression.

Build and device boundary
Target: iPhone, iOS 16+, native arm64 device and available compatible simulator.
Run bash ios/archive-device.sh on the Mac for an unsigned generic-device archive.
The exact-source simulator script now builds that archive before native tests.
Unsigned VoxelOne.xcarchive is not an installable iPhone artifact.
Simulator validation needs the controller's Mac result and actual media inspection.
30 FPS is the initial requested baseline, not a measured physical-device result.

Next coherent slices (all still required)

   exact geometry picking/collision/rendering, model persistence.
2. Incremental procedural chunks, bounded worker queues, cancellation and memory
   pressure; move generation/meshing/save encoding off the main thread safely.
3. Remaining crafting recipes, fly, camera/settings, landscape-first layout
   and recovery.
4. Sandbox authenticated multiplayer edit/resync tests, denied-network handling,
   isolated HTTPS proxy health checks, then root-coordinated live service checks.
5. Signed device delivery, install/update guide and versioned artifact checksums;
   physical iPhone gameplay/performance/thermal/battery qualification.

Signing remains separate. No Apple team, device registration or protected signing
provisioning has been established by this slice. Do not publish, purchase, invite,
or claim installation. Continue engineering while the delivery route is pending.

Crafting increment
The native Craft sheet uses IDs 88,89,90,91,92,94 exported from Java Crafting.
The bundled JSON and gateway snapshots share the same exporter; a Java test checks
catalog/asset equality. Old saves without recipes use the bundled catalog. Missing
inputs or full output storage reject atomically. This bounded offline mode has no
craft overflow drops; online overflow remains governed by the real Java server.
Model, fractional and tool recipes remain gated on the detail/item schema port.
Regenerate the catalog after deliberate recipe changes:
  mvn -q -DskipTests compile
  java -cp target/classes dev.jayms.net.mobile.MobileSnapshot --recipes ios/Resources/recipes.json
