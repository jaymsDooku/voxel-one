# Alien planet crash and awakening validation

Implemented in the existing Space Invaders browser client. Clearing the final level 2 fighter starts a 2 s crash, 1.2 s unconscious blackout, then a 3 s level 3 awakening. Combat stops during the scene. The player sees stepped alien terrain, wreckage and two voxel moons. Level 3 keeps the planet backdrop during fighter combat. Score and lives survive. Pause and background blur freeze the scene; restart clears it. Elapsed time remains capped at 0.05 s per update for suspended tabs.

Playtest: Linux headless Playwright WebKit, fresh synthetic profiles, exact local source served by `python3 -m http.server 8779 --bind 127.0.0.1`. Viewports: 1280×900, 390×844, 844×390. The harness creates a synthetic final fighter, then uses the real Fire key and running animation loop to earn the kill. It watches crash → blackout → waking → combat, pauses/resumes the crash, checks score/lives, flies and fires on level 3, checks blur pause and restart.
