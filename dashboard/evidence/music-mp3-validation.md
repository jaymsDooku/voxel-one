## Implementation

The bundled Java Sound MP3SPI 1.9.5.4 provider decodes MP3 into the existing signed 16-bit PCM/OpenAL/FFT pipeline. The client JAR merges service descriptors. Existing mono/stereo and 8–96 kHz validation remains. Input and decoded source PCM limits remain 32 MiB; mono-to-stereo expansion remains unchanged. MP3 delay/padding can remain. No network audio service or external runtime codec is used.

Fixtures are original synthetic audio generated by `deploy/generate_music_mp3_fixtures.py` using local LAME. Both are 44100 Hz and six seconds (100 Hz followed by 1000 Hz, three seconds each). Parsed MPEG Layer III headers show 232 frames per fixture: CBR stereo uses only 128 kbit/s; VBR mono uses 32, 40, 80, 96, 128 and 192 kbit/s.
